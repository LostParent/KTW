# Kuwait Tourism Website

A modern web application designed to promote tourism in Kuwait.

## Tech Stack

### Frontend
- **Framework:** [Next.js](https://nextjs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **HTTP Client:** [Axios](https://axios-http.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Maps Integration:** [Google Maps API](https://developers.google.com/maps)



### Backend
- **Framework:** [Django](https://www.djangoproject.com/)
- **API:** [Django REST Framework](https://www.django-rest-framework.org/)
- **Authentication:** [JWT (SimpleJWT)](https://django-rest-framework-simplejwt.readthedocs.io/)
- **Database:** [PostgreSQL](https://www.postgresql.org/)
- **Language:** [Python](https://www.python.org/)



### DevOps & Deployment
- [Docker](https://www.docker.com/) & Docker Compose — Containerization of the full system  
- [Nginx](https://nginx.org/) — Reverse proxy for routing and traffic management  
- [Certbot (Let’s Encrypt)](https://letsencrypt.org/) — SSL certificates for HTTPS security  
- [Hostinger VPS](https://www.hostinger.com/vps-hosting) — Cloud server used for deployment  



### Testing Tools
- [Postman](https://www.postman.com/) — Used for testing API endpoints and responses  
- [Chrome DevTools](https://developer.chrome.com/docs/devtools/) — Used for debugging frontend, performance analysis, and responsive design testing  
- [JMeter](https://jmeter.apache.org/) — Used for performance testing, load testing, and system stress testing under heavy traffic  



## Project Structure

- `frontend/` → Next.js application (UI and user experience)  
- `backend/` → Django REST API (backend logic and data management)  
- `database/` → PostgreSQL database used for storing tourism data and user information  


## Project Purpose

This project was developed as part of **Senior Project G96 (Spring 2026)**. It aims to improve tourism accessibility in Kuwait by providing a modern, fast, and user-friendly web platform that centralizes all tourism information in one place.
